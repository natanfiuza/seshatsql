# ADR 0008-distribuicao
Status: Aceito produto; técnica candidata.

## Contexto
Decisões das entrevistas 1–6; ver requisitos consolidados.

## Decisão
Instalador Windows por usuário; sem portable e auto-update inicialmente. Electron-builder candidato aprovado para spike.

## Consequências e limites
AppId/publisher/certificado pendentes; testar usuário não admin e preservação de dados ao desinstalar, sem política inventada.

## Evidência
Aprovação do usuário na conversa; implementação e testes ainda não executados.
