# ADR 0009-nome
Status: Aceito nome; diretório pendente.

## Contexto
Decisões das entrevistas 1–6; ver requisitos consolidados.

## Decisão
Nome vigente SeshatSQL substitui SQLSeshat em docs e UI futura.

## Consequências e limites
Não mudar caminho ~/.sqlseshat/data/ até aprovação P01; não confundir nome com disponibilidade de marca.

## Evidência
Aprovação do usuário na conversa; implementação e testes ainda não executados.
