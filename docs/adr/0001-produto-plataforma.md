# ADR 0001-produto-plataforma
Status: Aceito.

## Contexto
Decisões das entrevistas 1–6; ver requisitos consolidados.

## Decisão
Electron/TypeScript/Vue 3, Windows 11 x64, UI própria e MVP MySQL. Paridade incremental; não copiar/traduzir HeidiSQL.

## Consequências e limites
Menor escopo inicial; bibliotecas aprovadas só para experimentação. Outras plataformas/bancos não entram silenciosamente.

## Evidência
Aprovação do usuário na conversa; implementação e testes ainda não executados.
