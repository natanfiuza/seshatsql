- conexão/desconexão pela UI a partir de perfil salvo; senha decifrada só no main;
- estados desconectado, conectando, conectado, erro e unknown, com erros localizados;
- uma única sessão de trabalho; auxiliar só para KILL QUERY/KILL CONNECTION e
  leitura de estado, nunca SQL arbitrário;
- desconexão com execução ativa: cancelar e aguardar confirmação do servidor;
- transação aberta: rollback, commit explícito ou cancelar o fechamento, nunca
  commit silencioso;
- falha de rede não reexecuta SQL; estado unknown bloqueia escrita;
- IPC nomeado/validado, sem invoke genérico, driver ou credencial no renderer;
- testes unitários/componente/e2e e evidência; sem dependências novas sem
  licença/versão registradas.
