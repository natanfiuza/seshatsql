# Glossário — adições v1.1
Fechamento controlado: saída coordenada pelo aplicativo, distinta de encerramento forçado ou queda de energia.
Referência de perfil indisponível: aba preservada cujo perfil não está mais disponível; SQL não é descartado.
Preservação na desinstalação: remoção do aplicativo sem exclusão do diretório de dados aprovado.
Etapa 0: inspeção e planejamento técnico; não é scaffold nem homologação.
Complemento normativo: atualiza decisões específicas da baseline; não é substituto de todos os documentos anteriores.
